How it works

Every laptop port, adapter, cable, charger and display is a small graph inside a Relate database that runs right here in your browser (WebAssembly). Signals hop through an item (a VIDEO or POWER relationship that carries its Gbps or watts) and across a plug-and-socket joint (MATES). One Cypher query finds a chain from your laptop's GPU to the venue's panel where every hop carries the picture you want. The hop with the lowest capacity is the weakest link.

Each capacity comes from the standard the item follows (HDMI, DisplayPort, USB PD) or from the maker's spec page. Each one carries a source link and a confidence level. Limits are conservative (8-bit colour, no compression), so a "no" can sometimes work in practice, but a "yes" should not fail.

Ask the agent

The same graph is served over MCP by relate serve --mcp, so an assistant in Claude Desktop, Cursor or VS Code can use it. Paste a venue's AV email or an adapter's spec page. The agent writes the venue or item into your own copy of the graph, with its source and a confidence level, then runs these same queries. It tells you what to pack, which link is the weakest, and the one thing worth buying. The repo has ready-made client configs and an offline demo (python3 scripts/agent_demo.py) that needs no AI model and no API key. See agent/README.md.
