# Weakest Link recipes, check queries and schemas

Generated by `scripts/build_agent_docs.py`; do not edit by hand. The same recipes are stored as
`:Recipe` nodes in the writable `weakest-link-mybag` store, so you can also fetch them with
`MATCH (r:Recipe {name: $name}) RETURN r.cypher`.

Read recipes go to `read_cypher`, write recipes to `write_cypher`. Pass the text verbatim and put
your values in `parameters`.

## `reach` (read)

Can the laptop drive the venue's display at a mode with the bag plus what the venue provides? Returns ok, the shortest working chain, its weakest link and every hop's source and confidence.

Example `parameters`:

```json
{
  "laptop": "mba-m2",
  "venue": "meetup-hall",
  "bag": [
    "adp-apple-av-a1621"
  ],
  "mode": "4K60"
}
```

```cypher
// Q1 reachability: can $laptop drive the display at venue $venue at $mode, using only
// items in $bag plus what the venue provides? Returns the shortest working chain and its bottleneck.
// Params: $laptop (Item.id), $venue (Venue.id), $bag (list of Item.id), $mode (Mode.id)
MATCH (m:Mode {id: $mode}), (v:Venue {id: $venue})
MATCH (:Item {id: $laptop})-[:HAS_ENDPOINT]->(src:Endpoint {role: 'video-source'})
MATCH (v)-[:PROVIDES]->(d:Item {kind: 'display'})-[:HAS_ENDPOINT]->(sink:Endpoint {role: 'video-sink'})
WITH m, v, d, src, sink,
     [(v)-[:PROVIDES]->(i:Item) | i.id] + $bag + [$laptop] AS have,
     EXISTS { (sink)-[:SUPPORTS_MODE]->(m) } AS panel_ok
OPTIONAL MATCH p = SHORTEST 1
  (src)-[f:VIDEO WHERE f.gbps >= m.gbps]->()
  (()-[mt:MATES WHERE mt.from_item IN have AND mt.to_item IN have]->()
     -[vv:VIDEO WHERE vv.item IN have AND vv.gbps >= m.gbps]->()){1,6}
  (sink)
WITH m, v, d, panel_ok, p, [r IN relationships(p) WHERE type(r) = 'VIDEO'] AS links
WITH m, v, d, panel_ok, p, links,
     reduce(lo = 1.0e9, r IN links | CASE WHEN r.gbps < lo THEN r.gbps ELSE lo END) AS bottleneck
RETURN v.id AS venue, d.id AS display, m.id AS mode, m.gbps AS need_gbps,
       panel_ok AND p IS NOT NULL AS ok,
       panel_ok,
       [r IN links | r.item] AS chain,
       CASE WHEN p IS NULL THEN null ELSE bottleneck END AS bottleneck_gbps,
       [r IN links WHERE r.gbps = bottleneck | r.item][0] AS weakest_item,
       [r IN links | {item: r.item, gbps: r.gbps, standard: r.standard, confidence: r.confidence, source_url: r.source_url, note: r.note}] AS hops,
       [r IN relationships(p) WHERE type(r) = 'MATES' | r.connector] AS joints
ORDER BY ok DESC
LIMIT 1
```

## `chains` (read)

Every distinct chain from the laptop to the venue's display, widest first, with the weakest link, its standard, confidence and source, and the best mode the chain carries.

Example `parameters`:

```json
{
  "laptop": "mba-m2",
  "venue": "meetup-hall",
  "bag": [
    "adp-apple-av-a1621"
  ]
}
```

```cypher
// Q2 bottleneck analysis: every physically valid chain from $laptop to the venue display using
// $bag + venue items, widest first. For each chain: the weakest link (lowest-capacity edge),
// its standard, citation and confidence, and the best mode the chain can carry.
// Params: $laptop, $venue, $bag
MATCH (v:Venue {id: $venue})
MATCH (:Item {id: $laptop})-[:HAS_ENDPOINT]->(src:Endpoint {role: 'video-source'})
MATCH (v)-[:PROVIDES]->(d:Item {kind: 'display'})-[:HAS_ENDPOINT]->(sink:Endpoint {role: 'video-sink'})
WITH v, d, src, sink, [(v)-[:PROVIDES]->(i:Item) | i.id] + $bag + [$laptop] AS have
MATCH p = (src)-[:VIDEO]->()
  (()-[mt:MATES WHERE mt.from_item IN have AND mt.to_item IN have]->()
     -[vv:VIDEO WHERE vv.item IN have]->()){1,6}
  (sink)
// a physical item can only be used once in a chain
WHERE all(k IN range(0, size(nodes(p)) - 2) WHERE NOT nodes(p)[k] IN nodes(p)[k + 1..])
WITH v, d, sink, p, [r IN relationships(p) WHERE type(r) = 'VIDEO'] AS links,
     [r IN relationships(p) WHERE type(r) = 'MATES' | r.connector] AS joints
WITH v, d, sink, p, links, joints,
     reduce(lo = 1.0e9, r IN links | CASE WHEN r.gbps < lo THEN r.gbps ELSE lo END) AS bottleneck
// the same items can connect through different ports or cable orientations: keep one row per item chain
WITH sink, [r IN links | r.item] AS chain, bottleneck, [r IN links WHERE r.gbps = bottleneck][0] AS weak,
     [r IN links | {item: r.item, gbps: r.gbps, standard: r.standard, confidence: r.confidence, source_url: r.source_url, note: r.note}] AS hops, joints
ORDER BY bottleneck DESC
WITH sink, chain, collect({bottleneck: bottleneck, weak: weak, hops: hops, joints: joints})[0] AS best
OPTIONAL MATCH (sink)-[:SUPPORTS_MODE]->(m:Mode) WHERE m.gbps <= best.bottleneck
WITH chain, best, m ORDER BY m.rank DESC
WITH chain, best, collect(m.id) AS modes
RETURN chain,
       best.bottleneck AS bottleneck_gbps,
       best.weak.item AS weakest_item, best.weak.standard AS weakest_standard,
       best.weak.confidence AS weakest_confidence, best.weak.source_url AS weakest_source,
       modes[0] AS best_mode,
       best.hops AS hops, best.joints AS joints
ORDER BY bottleneck_gbps DESC, size(chain) ASC
```

## `best_fix` (read)

The single purchasable item that makes the mode work at the most failing venues in $venues.

Example `parameters`:

```json
{
  "laptop": "mba-m2",
  "bag": [
    "adp-apple-av-a1621"
  ],
  "venues": [
    "meetup-hall",
    "studio-tv"
  ],
  "mode": "4K60"
}
```

```cypher
// Q3 best single purchase: across the venues in $venues, which ONE purchasable item, added to
// $bag, makes $mode work at the most venues that fail today?
// Params: $laptop, $bag, $venues (list of Venue.id), $mode
// Written without CALL subqueries so that Relate's MCP read_cypher tool accepts it: each
// OPTIONAL MATCH ... SHORTEST 1 runs once per incoming row.
MATCH (m:Mode {id: $mode})
MATCH (:Item {id: $laptop})-[:HAS_ENDPOINT]->(src:Endpoint {role: 'video-source'})
UNWIND $venues AS vid
MATCH (v:Venue {id: vid})-[:PROVIDES]->(:Item {kind: 'display'})-[:HAS_ENDPOINT]->(sink:Endpoint {role: 'video-sink'})
WITH m, src, v, sink,
     [(v)-[:PROVIDES]->(i:Item) | i.id] + $bag + [$laptop] AS have,
     EXISTS { (sink)-[:SUPPORTS_MODE]->(m) } AS panel_ok
OPTIONAL MATCH p = SHORTEST 1
  (src)-[f:VIDEO WHERE f.gbps >= m.gbps]->()
  (()-[mt:MATES WHERE mt.from_item IN have AND mt.to_item IN have]->()
     -[vv:VIDEO WHERE vv.item IN have AND vv.gbps >= m.gbps]->()){1,6}
  (sink)
WITH m, src, v, sink, have, panel_ok AND p IS NOT NULL AS ok_now
WITH m, src, collect(CASE WHEN ok_now THEN null ELSE {venue: v.id, sink: sink, have: have, panel_ok: EXISTS { (sink)-[:SUPPORTS_MODE]->(m) }} END) AS failing,
     collect(CASE WHEN ok_now THEN v.id END) AS ok_venues
UNWIND failing AS fv
MATCH (c:Item {purchasable: true}) WHERE NOT c.id IN fv.have
WITH m, src, failing, ok_venues, fv, c, fv.sink AS sink, fv.have + [c.id] AS have2
OPTIONAL MATCH p = SHORTEST 1
  (src)-[f:VIDEO WHERE f.gbps >= m.gbps]->()
  (()-[mt:MATES WHERE mt.from_item IN have2 AND mt.to_item IN have2]->()
     -[vv:VIDEO WHERE vv.item IN have2 AND vv.gbps >= m.gbps]->()){1,6}
  (sink)
WITH failing, ok_venues, c, fv, p IS NOT NULL AND fv.panel_ok AS fixed
WITH failing, ok_venues, c, collect(CASE WHEN fixed THEN fv.venue END) AS fixed_venues
WHERE size(fixed_venues) > 0
RETURN c.id AS buy, c.name AS name, size(fixed_venues) AS venues_fixed, fixed_venues,
       [x IN failing WHERE NOT x.venue IN fixed_venues | x.venue] AS still_failing,
       ok_venues AS already_ok
ORDER BY venues_fixed DESC, buy
```

## `power` (read)

For each charger in the bag, the best charger-cable-laptop chain in watts and a verdict (fast-charge, full-speed, below-recommended, unknown).

Example `parameters`:

```json
{
  "laptop": "mba-m2",
  "bag": [
    "chg-apple-70w",
    "cable-usbc-usb2-60w"
  ]
}
```

```cypher
// Q4 USB-PD charging chain: for every power source in $bag (a charger, or a dock or monitor with its own supply), the best way to reach $laptop's battery
// using cables in $bag, the delivered wattage (min over the chain), the weakest link, and a verdict
// against the laptop's documented recommended / fast-charge wattage. capacity_w is what the chain
// can carry; the laptop itself draws only what it needs.
// Params: $laptop, $bag
MATCH (lap:Item {id: $laptop})-[:HAS_ENDPOINT]->(bat:Endpoint {role: 'power-sink'})
MATCH (chg:Item)-[:HAS_ENDPOINT]->(psu:Endpoint {role: 'power-source'})
WHERE chg.id IN $bag
WITH lap, bat, chg, psu, $bag + [$laptop] AS have
MATCH p = (psu)-[:POWER]->()
  (()-[mt:MATES WHERE mt.from_item IN have AND mt.to_item IN have]->()
     -[pw:POWER WHERE pw.item IN have]->()){1,4}
  (bat)
WHERE all(k IN range(0, size(nodes(p)) - 2) WHERE NOT nodes(p)[k] IN nodes(p)[k + 1..])
WITH lap, chg, [r IN relationships(p) WHERE type(r) = 'POWER'] AS links,
     [r IN relationships(p) WHERE type(r) = 'MATES' | r.connector] AS joints
WITH lap, chg, links, joints,
     reduce(lo = 1.0e9, r IN links | CASE WHEN r.watts IS NOT NULL AND r.watts < lo THEN r.watts ELSE lo END) AS watts
WITH lap, chg, [r IN links | r.item] AS chain, watts,
     [r IN links WHERE r.watts = watts][0] AS weak,
     [r IN links | {item: r.item, watts: r.watts, standard: r.standard, confidence: r.confidence, source_url: r.source_url, note: r.note}] AS hops, joints
ORDER BY watts DESC, size(chain) ASC
WITH lap, chg, collect({chain: chain, watts: watts, weak: weak, hops: hops, joints: joints})[0] AS best
RETURN chg.id AS charger, best.chain AS chain, best.watts AS capacity_w,
       best.weak.item AS weakest_item, best.weak.source_url AS weakest_source,
       lap.pd_recommended_w AS recommended_w, lap.pd_fast_w AS fast_w,
       CASE
         WHEN lap.pd_fast_w IS NOT NULL AND best.watts >= lap.pd_fast_w THEN 'fast-charge'
         WHEN lap.pd_recommended_w IS NOT NULL AND best.watts >= lap.pd_recommended_w THEN 'full-speed'
         WHEN lap.pd_recommended_w IS NULL THEN 'unknown'
         ELSE 'below-recommended'
       END AS verdict,
       best.hops AS hops, best.joints AS joints
ORDER BY capacity_w DESC
```

## `ingest_venue` (write)

Write a venue (from an email or web page) as Venue + display Item + ports + cited VIDEO edges. Idempotent per venue id. Param $v follows agent/schemas/venue.schema.json.

Example `parameters`:

```json
{
  "v": {
    "id": "riverside-library-room-2",
    "name": "Riverside Library, Room 2",
    "confidence": "medium",
    "source": {
      "id": "email-riverside",
      "kind": "email",
      "supports": "Full HD projector, HDMI and VGA inputs"
    },
    "display": {
      "name": "Room 2 projector",
      "max_mode": "1080p60",
      "inputs": [
        {
          "connector": "HDMI",
          "standard": "HDMI-1.4"
        }
      ]
    },
    "provides": [
      "cable-hdmi-standard"
    ]
  }
}
```

```cypher
// Ingest (or re-ingest) a venue described in an email, a booking page or a tech-rider PDF.
// ONE write statement, so it can be sent as-is through MCP `write_cypher`.
// Param $v (see agent/schemas/venue.schema.json):
//   {id, name, description, confidence, source: {id, kind, publisher, title, url, supports},
//    display: {name, max_mode, inputs: [{connector, standard, confidence, note}]},
//    provides: [catalog Item.id]}
// It refuses to overwrite a catalog venue: if $v.id names a venue that was not ingested, it
// writes nothing (MCP write_cypher then reports nodes_created = 0).
// The display becomes Item `<id>-display` with an input Port per input, a panel Endpoint,
// VIDEO edges at the input standard's data rate, MATES to every compatible plug in the graph,
// and SUPPORTS_MODE up to max_mode. Every new edge carries the source and confidence.
OPTIONAL MATCH (clash:Venue {id: $v.id})
WITH clash WHERE clash IS NULL OR clash.ingested = true
CALL () {
  OPTIONAL MATCH (n) WHERE n.id = $v.id + '-display' OR n.item = $v.id + '-display'
  DETACH DELETE n
}
CALL () {
  OPTIONAL MATCH (old:Venue {id: $v.id})
  DETACH DELETE old
}
MERGE (src:Source {id: $v.source.id})
SET src.kind = coalesce($v.source.kind, 'email'), src.publisher = $v.source.publisher,
    src.title = $v.source.title, src.url = $v.source.url, src.supports = $v.source.supports,
    src.ingested = true
CREATE (ven:Venue {id: $v.id, name: $v.name, description: $v.description,
                   source: $v.source.id, confidence: $v.confidence, ingested: true})
CREATE (d:Item {id: $v.id + '-display', kind: 'display', class: 'ingested', name: $v.display.name,
                purchasable: false, license: 'user', confidence: $v.confidence, ingested: true})
CREATE (e:Endpoint {id: $v.id + '-display:panel', item: $v.id + '-display', name: 'panel', role: 'video-sink'})
CREATE (d)-[:HAS_ENDPOINT]->(e), (ven)-[:PROVIDES]->(d), (d)-[:CITES]->(src)
WITH ven, d, e, src
CALL (d, e, src) {
  UNWIND range(0, size($v.display.inputs) - 1) AS k
  WITH d, e, src, k, $v.display.inputs[k] AS inp
  MATCH (s:Standard {id: inp.standard})
  CREATE (p:Port {id: d.id + ':in' + toString(k + 1), item: d.id, name: toLower(inp.connector) + toString(k + 1),
                  connector: inp.connector, gender: 'receptacle', dual_mode: false, requires_dual_mode: false})
  CREATE (d)-[:HAS_PORT]->(p)
  CREATE (p)-[:VIDEO {item: d.id, from_item: d.id, to_item: d.id, gbps: s.data_gbps, standard: s.id,
                      source: src.id, source_url: src.url, confidence: coalesce(inp.confidence, $v.confidence),
                      note: coalesce(inp.note, 'From ' + coalesce(src.title, src.id))}]->(e)
  MERGE (d)-[:CONFORMS_TO]->(s)
  WITH d, p, d.id AS did, p.connector AS c
  MATCH (q:Port {gender: 'plug', connector: c})
  WHERE q.item <> did AND NOT q.requires_dual_mode
  WITH p, q, did, c, q.item AS qi
  CREATE (p)-[:MATES {from_item: did, to_item: qi, connector: c}]->(q)
  CREATE (q)-[:MATES {from_item: qi, to_item: did, connector: c}]->(p)
  RETURN count(*) AS mates
}
CALL (e) {
  MATCH (top:Mode {id: $v.display.max_mode}), (m:Mode) WHERE m.rank <= top.rank
  CREATE (e)-[:SUPPORTS_MODE]->(m)
  RETURN count(m) AS modes
}
CALL (ven) {
  UNWIND coalesce($v.provides, []) AS pid
  MATCH (i:Item {id: pid})
  CREATE (ven)-[:PROVIDES]->(i)
  RETURN count(i) AS provided
}
RETURN ven.id AS venue, d.id AS display, modes, provided
```

## `ingest_item` (write)

Write an adapter, cable or charger (from its spec page) as Item + ports + cited VIDEO/POWER edges and MATES to every compatible port. Ids start with my-. Param $it follows agent/schemas/item.schema.json.

Example `parameters`:

```json
{
  "it": {
    "id": "my-adp-usbc-hdmi20",
    "name": "USB-C to HDMI 2.0 adapter",
    "kind": "adapter",
    "confidence": "medium",
    "source": {
      "id": "spec-x",
      "kind": "manufacturer",
      "url": "https://example.org"
    },
    "ports": [
      {
        "name": "in",
        "connector": "USB-C",
        "gender": "plug"
      },
      {
        "name": "out",
        "connector": "HDMI",
        "gender": "receptacle"
      }
    ],
    "video": [
      {
        "from": "in",
        "to": "out",
        "standard": "HDMI-2.0"
      }
    ]
  }
}
```

```cypher
// Ingest (or re-ingest) an adapter, hub, cable or charger from its spec page.
// ONE write statement, so it can be sent as-is through MCP `write_cypher`.
// Param $it (see agent/schemas/item.schema.json):
//   {id, name, kind, maker, purchasable, confidence, source: {id, kind, publisher, title, url, supports},
//    ports: [{name, connector, gender, dual_mode, requires_dual_mode}],
//    endpoints: [{name, role}],                       // chargers only: {name:'psu', role:'power-source'}
//    video: [{from, to, standard, gbps, note, both_ways}],
//    power: [{from, to, standard, watts, note, both_ways}]}
// `from`/`to` are port or endpoint names. gbps defaults to the standard's data rate and watts to the
// standard's wattage, so a spec that only says "HDMI 2.0" still gets a cited number.
// It refuses to overwrite a catalog item: if $it.id names an item that was not ingested, it writes
// nothing (MCP write_cypher then reports nodes_created = 0). Use ids that start with `my-`.
OPTIONAL MATCH (clash:Item {id: $it.id})
WITH clash WHERE clash IS NULL OR clash.ingested = true
CALL () {
  OPTIONAL MATCH (n) WHERE n.id = $it.id OR n.item = $it.id
  DETACH DELETE n
}
MERGE (src:Source {id: $it.source.id})
SET src.kind = coalesce($it.source.kind, 'manufacturer'), src.publisher = $it.source.publisher,
    src.title = $it.source.title, src.url = $it.source.url, src.supports = $it.source.supports,
    src.ingested = true
CREATE (i:Item {id: $it.id, kind: $it.kind, class: 'ingested', name: $it.name, maker: $it.maker,
                purchasable: coalesce($it.purchasable, true), license: 'user',
                confidence: $it.confidence, ingested: true})
CREATE (i)-[:CITES]->(src)
WITH i, src
CALL (i) {
  UNWIND coalesce($it.ports, []) AS pt
  WITH i, pt, i.id AS iid
  CREATE (p:Port {id: iid + ':' + pt.name, item: iid, name: pt.name, connector: pt.connector,
                  gender: pt.gender, dual_mode: coalesce(pt.dual_mode, false),
                  requires_dual_mode: coalesce(pt.requires_dual_mode, false)})
  CREATE (i)-[:HAS_PORT]->(p)
  RETURN count(p) AS ports
}
CALL (i) {
  UNWIND coalesce($it.endpoints, []) AS ep
  WITH i, ep, i.id AS iid
  CREATE (e:Endpoint {id: iid + ':' + ep.name, item: iid, name: ep.name, role: ep.role})
  CREATE (i)-[:HAS_ENDPOINT]->(e)
  RETURN count(e) AS endpoints
}
CALL (i, src) {
  UNWIND coalesce($it.video, []) AS vd
  UNWIND CASE WHEN coalesce(vd.both_ways, false) THEN [[vd.from, vd.to], [vd.to, vd.from]] ELSE [[vd.from, vd.to]] END AS dir
  MATCH (s:Standard {id: vd.standard})
  MATCH (a) WHERE a.id = i.id + ':' + dir[0] AND (a:Port OR a:Endpoint)
  MATCH (b) WHERE b.id = i.id + ':' + dir[1] AND (b:Port OR b:Endpoint)
  CREATE (a)-[:VIDEO {item: i.id, from_item: i.id, to_item: i.id, gbps: coalesce(vd.gbps, s.data_gbps),
                      standard: s.id, source: src.id, source_url: src.url, confidence: $it.confidence,
                      note: vd.note}]->(b)
  MERGE (i)-[:CONFORMS_TO]->(s)
  RETURN count(*) AS video
}
CALL (i, src) {
  UNWIND coalesce($it.power, []) AS pw
  UNWIND CASE WHEN coalesce(pw.both_ways, false) THEN [[pw.from, pw.to], [pw.to, pw.from]] ELSE [[pw.from, pw.to]] END AS dir
  MATCH (s:Standard {id: pw.standard})
  MATCH (a) WHERE a.id = i.id + ':' + dir[0] AND (a:Port OR a:Endpoint)
  MATCH (b) WHERE b.id = i.id + ':' + dir[1] AND (b:Port OR b:Endpoint)
  CREATE (a)-[:POWER {item: i.id, from_item: i.id, to_item: i.id, watts: coalesce(pw.watts, s.watts),
                      standard: s.id, source: src.id, source_url: src.url, confidence: $it.confidence,
                      note: pw.note}]->(b)
  MERGE (i)-[:CONFORMS_TO]->(s)
  RETURN count(*) AS power
}
CALL (i) {
  MATCH (i)-[:HAS_PORT]->(p:Port), (q:Port)
  WHERE q.item <> i.id AND q.connector = p.connector AND q.gender <> p.gender
    AND NOT (p.gender = 'plug' AND p.requires_dual_mode AND NOT q.dual_mode)
    AND NOT (q.gender = 'plug' AND q.requires_dual_mode AND NOT p.dual_mode)
  WITH p, q, i.id AS iid, q.item AS qi, p.connector AS c
  CREATE (p)-[:MATES {from_item: iid, to_item: qi, connector: c}]->(q)
  CREATE (q)-[:MATES {from_item: qi, to_item: iid, connector: c}]->(p)
  RETURN count(*) AS mates
}
RETURN i.id AS item, ports, endpoints, video, power, mates
```

## Check queries (run after a write)

Venue (`parameters: {"id": "<venue id>"}`):

```cypher
MATCH (v:Venue {id: $id})-[:PROVIDES]->(d:Item {kind: 'display'})-[:HAS_ENDPOINT]->(e:Endpoint)
RETURN v.name AS venue, v.confidence AS confidence, d.id AS display,
       [(e)-[:SUPPORTS_MODE]->(m:Mode) | m.id] AS modes,
       [(d)-[:HAS_PORT]->(p:Port)-[x:VIDEO]->(e) | {connector: p.connector, gbps: x.gbps, standard: x.standard, confidence: x.confidence}] AS inputs,
       [(v)-[:PROVIDES]->(c:Item) WHERE c.kind <> 'display' | c.id] AS provides,
       COUNT { (d)-[:HAS_PORT]->(:Port)-[:MATES]->(:Port) } AS joints,
       [(d)-[:CITES]->(s:Source) | s.id][0] AS source
```

Item (`parameters: {"id": "<item id>"}`):

```cypher
MATCH (i:Item {id: $id})
RETURN i.name AS name, i.confidence AS confidence,
       [(i)-[:HAS_PORT]->(p:Port) | p.name + ':' + p.connector + ':' + p.gender] AS ports,
       COUNT { (i)-[:HAS_PORT]->(:Port)-[:MATES]->(:Port) } AS joints,
       [(i)-[:HAS_PORT]->(:Port)-[x:VIDEO]->() | x.gbps] AS video_gbps,
       [(i)-[:HAS_PORT]->(:Port)-[x:POWER]->() | x.watts] AS power_w,
       [(i)-[:CITES]->(s:Source) | s.url][0] AS source_url
```

## Schema `item.schema.json`

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "weakest-link/item.schema.json",
  "title": "Adapter, hub, cable or charger extracted from a spec page (param $it of ingest_item)",
  "type": "object",
  "required": ["id", "name", "kind", "confidence", "source", "ports"],
  "properties": {
    "id": {"type": "string", "pattern": "^my-[a-z0-9-]+$", "description": "Ingested ids start with my- so they never clash with the catalog"},
    "name": {"type": "string"},
    "kind": {"enum": ["adapter", "cable", "charger"]},
    "maker": {"type": "string"},
    "purchasable": {"type": "boolean", "default": true},
    "confidence": {"enum": ["high", "medium", "low"], "description": "high only for the maker's own spec page that states the standard"},
    "source": {
      "type": "object",
      "required": ["id", "kind"],
      "properties": {
        "id": {"type": "string"},
        "kind": {"enum": ["manufacturer", "retailer", "review", "user"]},
        "publisher": {"type": "string"},
```
